Create a WhatsApp QR Code

A WhatsApp QR code opens a chat with a designated WhatsApp number. It can be useful for customer questions, event registrations or product inquiries without requiring visitors to manually save a phone number.

Create this QR code →Browse other guides

Build your chat link

  1. Open QR Studio and choose WhatsApp under More QR Types.
  2. Enter the phone number with country code. Make sure it is an active WhatsApp number.
  3. Optionally enter a short prefilled message, such as “Hello, I would like more details.”
  4. Generate the QR code and test it on a device where WhatsApp is installed or accessible.

Use the QR code effectively

  1. Label the printed code with a clear action such as “Message us on WhatsApp.”
  2. Place the code on a flyer, counter sign, website or event material where people can scan it.
  3. Download SVG or PNG and verify that the link opens the correct conversation, including the intended prefilled text.

Important things to know

WhatsApp availability and account status are outside QR Studio. Creating a QR code does not create a WhatsApp account.

People who scan the code may be able to see the phone number in the destination link.

Do not add confidential information to prefilled messages. Scanners may show the encoded URL before opening it.

Frequently asked questions

Do I need a WhatsApp Business account?

No. The QR points to a WhatsApp chat link. Your number must be reachable through WhatsApp.

Can I add a prefilled greeting?

Yes. QR Studio can add text to the link; the person opening WhatsApp can edit the message before sending.

Does the code expire?

The static QR code does not expire, but it will stop being useful if the WhatsApp number no longer works.
